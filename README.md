# 接力剪贴板 · Harmony Clipboard

一个轻量的 macOS 剪贴板面板，可通过局域网无线调试，与鸿蒙手机同步文字。按 **Control+X** 呼出，选择历史记录后回车，粘贴到原应用。

**这是个人开源工具，不是华为官方跨设备剪贴板。** 手机端不需要安装 HAP，但需要开发者选项、无线调试，以及对这台 Mac 的调试授权。实现依赖手机系统提供的 `hdc` / `testhelper` 调试能力，系统更新可能改变可用性。请先用普通文字确认自己的机型兼容。

[下载 Release](https://github.com/gengyu12138/harmony-clipboard/releases) · [反馈问题](https://github.com/gengyu12138/harmony-clipboard/issues) · [MIT 许可证](LICENSE)

## 能做什么

| 功能 | 当前支持情况 |
| --- | --- |
| Mac 文字和图片历史 | 支持；记录应用启动后观察到的复制内容 |
| 搜索、类型/设备筛选、收藏、置顶、单条删除 | 支持 |
| 回车、双击、⌘1–9 直接粘贴 | 支持；需要辅助功能权限，目标应用需要支持对应内容的粘贴 |
| Mac ↔ 鸿蒙手机文字 | 自动双向同步；另有“取手机文字”和每条文字的“发送到手机”按钮 |
| 手机当前屏幕 → Mac 图片 | 点击“手机截图”；取回后可预览、复制和粘贴 |
| 手机 IP / 端口设置 | 面板右上角齿轮；保存后连接，不必编辑脚本 |
| 断线重连、登录自启 | 支持；启动后只在后台运行，不自动弹窗 |
| 自动发现变化后的 IP / 端口 | 不支持；地址不变时自动重连，变化后需在设置更新 |
| Mac 图片 → 手机剪贴板 | 不支持 |
| 手机图片剪贴板 → Mac | 不支持；“手机截图”不是读取手机图片剪贴板 |
| 读取手机或 Mac 安装前的完整剪贴板历史 | 不支持 |
| Mac 截图、长截图、改图 | 不包含 |

## 使用条件

- **Apple Silicon Mac（arm64）**，构建最低目标为 macOS 14。当前真实使用验证环境为 macOS 26.7.2；未逐一验证较旧系统，未提供 Intel 安装包。
- `/usr/bin/python3` 可运行。源码编译还需要 Xcode 或 Command Line Tools 中的 Swift 工具链。安装程序不会自动安装开发环境。
- 一部支持无线调试，并允许 `testhelper get-pastedata` / `set-pastedata` 的鸿蒙手机。当前在用户的华为 Mate 80 上验证，其他机型和系统版本未逐一验证。
- Mac 与手机处于互相可访问的局域网。相同 Wi-Fi 名称不代表一定互通，访客网络、AP 隔离、防火墙或 VPN 规则可能阻止连接。
- 与手机系统兼容的官方 **macOS arm64 hdc**。本仓库和安装包均不附带华为 SDK、hdc 二进制、调试密钥或设备授权。

获取工具请从[华为 Command Line Tools 下载页](https://developer.huawei.com/consumer/cn/download/command-line-tools-for-hmos)或[华为开发者下载中心](https://developer.huawei.com/consumer/cn/download/)进入；以官方页面中的平台、版本和协议为准。工具使用方式参考[官方 hdc 文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hdc)。下载后找到工具目录中的 `hdc`，保留同目录依赖库。项目也可参考 [OpenHarmony hdc 源码](https://github.com/openharmony/developtools_hdc)，但不能假定任意 hdc 版本都兼容商业鸿蒙手机。

## 安装

### 1. 下载并核对安装包

从 Release 下载 `HarmonyClipboard-1.1.0-macOS-arm64.zip` 和同名 `.sha256` 文件。在两者所在目录运行：

```sh
shasum -a 256 -c HarmonyClipboard-1.1.0-macOS-arm64.zip.sha256
```

应返回 `OK`。然后解压，进入解压目录。

### 2. 安装到当前用户

在终端运行下列命令，将示例路径替换为自己下载的官方 hdc 可执行文件路径：

```sh
./install.command --hdc "/你的工具目录/hdc"
```

不需要 `sudo`。安装器会：

1. 将应用安装到 `~/Applications/接力剪贴板.app`。
2. 将项目同步脚本复制到 `~/Library/Application Support/HarmonyClipboard/`。
3. 将指定的 `hdc` 和同目录存在的 `libusb_shared.dylib` 复制到上述目录的 `bin/`。其他版本若需要额外依赖库，需先核查兼容性；安装器不会从网络补下载。
4. 创建当前用户的面板与同步 LaunchAgent。面板立即在后台启动；新安装的手机同步服务在填写连接地址后启动。

只想使用本机历史面板，可不传 `--hdc`：

```sh
./install.command
```

已有安装可用同一命令升级。升级会短暂退出应用并停止同步，保留历史、收藏、置顶、手机地址和已有调试授权文件；此前主动暂停的手机同步不会因升级自动恢复。进程内尚未发送的同步文字不会跨重启保留。

**安装包使用本地 ad-hoc 签名，没有 Apple Developer ID 签名或公证。** macOS 可能拦截首次运行。请核对来源、校验和及源码，按系统提供的正常授权流程处理；不要关闭 Gatekeeper 或全局安全保护。不愿运行未公证包时可从源码自行编译。升级改变签名后，辅助功能授权可能需要重新添加应用。

### 3. 设置手机连接

1. 在手机设置中开启开发者选项、无线调试。具体入口随系统版本变化。
2. 手机与 Mac 连到同一可互访网络，保持手机解锁。
3. 按 **Control+X** 呼出面板，点击右上角 **齿轮「手机连接设置」**。
4. 填写手机无线调试页面显示的 **IPv4 地址**和**端口**，点“保存并连接”。不要使用配对码，也不要猜测固定端口。
5. 如果手机出现调试授权弹窗，只在确认是自己的 Mac 时允许。有些系统需要先通过 USB 完成首次授权，之后才能使用无线连接。
6. 面板显示“手机已连接”后，用普通文字在两侧复制、粘贴测试。连接状态本身不代表所有剪贴板操作均被手机系统允许。

“保存并连接”也会启用手机同步的登录自启。IP 或端口变化后回到这里更新；同一地址断线会自动重试。无需一直打开 DevEco Studio 或终端，但同步脚本和 hdc 后台进程必须运行。

### 4. 启用直接粘贴（可选）

在 **系统设置 → 隐私与安全性 → 辅助功能**中添加并启用 `~/Applications/接力剪贴板.app`。

先点击目标应用的输入框，再按 Control+X，选记录后回车或双击。应用会切回原应用，发送一次 ⌘V。没有授权时仍能普通复制，再手动粘贴。本项目不需要 Mac 录屏权限；“手机截图”通过手机调试通道获取。

## 日常操作

| 操作 | 方法 |
| --- | --- |
| 呼出 / 收起 | Control+X；也可点菜单栏剪贴板图标 |
| 搜索 | ⌘F |
| 选择历史 | 鼠标单击或 ↑ / ↓ |
| 粘贴并收起 | 回车、双击记录或 ⌘1–9 |
| 只复制 | 预览区域“复制”按钮 |
| 收起 | Esc / 右上角关闭按钮 |
| 置顶 / 收藏 / 删除 | 预览区域按钮；记录右键菜单也可置顶或删除 |
| 固定面板 | 顶部图钉；与“记录置顶”是不同功能 |
| 取手机当前文字 | 顶部独立按钮；加入历史后选择复制 |
| 发送选定文字到手机 | 该条记录中的发送按钮 |
| 取手机当前画面 | 顶部“手机截图”按钮；截图完成前不要覆盖 Mac 剪贴板 |
| 暂停本机及手机历史采集 | “更多 → 暂停记录”；不会停止独立的文字同步服务 |
| 暂停 / 恢复文字同步 | “更多 → 暂停手机同步 / 恢复手机同步”；暂停同时关闭同步服务的登录自启 |

退出面板只退出历史面板，**不会停止独立的手机同步服务**。要完全停用，请先暂停手机同步，再退出面板。Control+X 会占用其他应用的同名快捷键（例如部分终端快捷键）；当前版本不支持自定义。

## 同步规则与限制

- 同步服务约每 0.8 秒检查一次，面板约每 4 秒采集一次手机当前文字；网络、锁屏和系统调度会增加延迟，不保证实时送达。
- 文字同步最大 **16 KB UTF-8**，不发送空文本或包含空字符的文本。不会同步图片、文件、富文本格式或剪贴板“清空”动作。
- 服务启动时以现有剪贴板为基线，不主动覆盖两侧旧内容。应在启动后重新复制要同步的文字。
- 检测到 Mac 新复制时优先发送；断线期间只保留进程观察到的最新一条待发文字，重连后可能覆盖手机当前剪贴板。这不是多设备合并或可靠消息队列。改 IP/端口会清除旧目标待发内容。
- 双方几乎同时复制可能互相覆盖，没有跨设备统一时间戳。重要内容先保存到文件，不要把剪贴板当持久存储。
- 实测手机锁屏时仍能接收 Mac 文字，解锁后可粘贴；手机→Mac 读取可能被系统拒绝。这只代表已测设备的表现，不能保证所有系统或长时间待机后的行为。
- 手机历史仅保存程序运行期间成功采集的当前内容。采集间隔内被替换的文字可能漏记；设备标签表示曾在哪一侧采集，不保证是内容的最初来源。
- 本机历史上限 **100 条 / 100 MB**，单条上限 **20 MB**。相同内容合并。自动清理优先移除非置顶、非收藏记录，再移除非置顶收藏记录；置顶不会被自动清理，空间全被置顶占用时新记录可能无法保留。
- 删除记录仅删除本机历史及对应图片，不会清空任一设备当前剪贴板；再次复制或重启后采集到相同当前内容，可能重新出现。历史删除无回收站。
- 手机截图会创建随机名的手机临时图片，传回后尝试删除。断线可能导致手机临时文件残留；截图还会作为历史保存在 Mac，不等同于自动删除。

## 隐私与注意事项

- 无云端账号、统计分析或远程上传服务；源码中的同步连接只指向用户配置的手机。hdc 私有服务绑定 Mac 回环地址 `127.0.0.1:18710`，不会主动扫描局域网。
- **历史以明文 JSON / 图片存储在本机，不额外加密**。目录创建权限为当前用户专用；系统管理员、获得足够权限的进程和备份软件仍可能访问。不要在历史中长期保留密码、令牌或工作机密。
- Mac 历史与自动同步会跳过已标记为 Concealed / Transient 或常见 1Password 类型的内容，但并非所有应用都会加标记；手机文字也可能包含敏感内容。此机制不能可靠识别所有秘密。
- 开启同步意味着复制的文字可能自动发送到已授权手机，手机文字也可能覆盖 Mac 当前剪贴板。处理工作资料前确认单位政策允许。暂时不需要时使用“暂停手机同步”，必要时同时暂停历史记录。
- 开发者调试授权远大于单纯剪贴板权限。只授权自己的可信 Mac，尽量在可信网络使用，不把调试端口映射到公网。不用时关闭手机无线调试，丢失设备或不再信任电脑时撤销调试授权。
- hdc 通过环境变量请求加密通道；最终传输行为取决于所用官方工具及设备。该项目没有独立审计或实现一套端到端加密协议。
- 提交 Issue 前删去剪贴板正文、个人 IP、设备标识和日志中的个人信息；不要上传 `config.json`、`history.json`、调试密钥或历史图片。

## 存储位置、服务与故障排查

| 位置 | 用途 |
| --- | --- |
| `~/Applications/接力剪贴板.app` | 面板和随包同步源码 |
| `~/Library/Application Support/HarmonyClipboardPanel/` | `history.json` 与历史图片 |
| `~/Library/Application Support/HarmonyClipboard/` | 同步脚本、`bin/hdc`、`config.json`、状态和有限滚动日志 |
| `~/Library/LaunchAgents/local.gengyu.harmony-panel.plist` | 登录后台启动面板；主动退出后不会强行拉起 |
| `~/Library/LaunchAgents/local.gengyu.harmony-clipboard.plist` | 文字同步后台服务；运行时异常退出后重试 |

`config.json` 由设置生成，仅必需 `endpoint`（`IPv4:端口`）。日志不主动记录剪贴板正文，但历史记录会保存正文。不要将运行目录直接作为 Git 仓库提交。

- **无法呼出**：先从 `~/Applications` 打开应用，或点菜单栏图标；检查 Control+X 是否被其他软件占用。
- **无法连接**：检查手机解锁、无线调试、授权弹窗和当前 IP/端口，再检查访客 Wi-Fi / 网络隔离 / VPN。地址相同且失败会按 2–30 秒退避重连。
- **显示连接但读不到手机文字**：解锁后重新复制普通短文字；检查手机是否提供 `testhelper`。不能用连接成功替代剪贴板功能验证。
- **已复制但没直接粘贴**：确认辅助功能权限、目标输入框焦点；更新后尝试在系统设置中重新添加应用。也可用“复制”后手动 ⌘V。
- **手机组件未安装**：按安装步骤重新运行 `install.command --hdc ...`；仅拖动 app 不会安装手机同步后台服务。
- **服务冲突**：同步使用回环端口 18710；其他 hdc / DevEco 调试会话可能产生冲突。先确认有哪些会话，不要直接结束别人的调试进程。

查看同步状态（输出含自己的连接地址，分享前脱敏）：

```sh
/usr/bin/python3 -B "$HOME/Library/Application Support/HarmonyClipboard/sync.py" status
```

停止或恢复同步：

```sh
/usr/bin/python3 -B "$HOME/Library/Application Support/HarmonyClipboard/sync.py" stop
/usr/bin/python3 -B "$HOME/Library/Application Support/HarmonyClipboard/sync.py" start
```

## 卸载

1. 面板“更多 → 暂停手机同步”，再退出接力剪贴板。
2. 在终端卸载两个登录服务（已经停止的服务可能提示未找到）：

   ```sh
   launchctl bootout "gui/$(id -u)/local.gengyu.harmony-panel"
   launchctl bootout "gui/$(id -u)/local.gengyu.harmony-clipboard"
   ```

3. 在 Finder 将上表中的应用、两份 LaunchAgent plist 移到废纸篓。
4. 两个 Application Support 目录包含历史及配置。需要保留时先备份；确认不再需要后再手动移到废纸篓。删除应用本身不会清除这些数据。
5. 在系统设置撤销本应用的辅助功能授权，并在手机关闭无线调试或撤销电脑调试授权。不要为卸载本工具删除其他开发工具共用的密钥。

## 从源码构建与打包

```sh
git clone https://github.com/gengyu12138/harmony-clipboard.git
cd harmony-clipboard
./build.sh
./install.command --hdc "/你的官方工具目录/hdc"
```

`build.sh` 使用系统 `swiftc` 和原生 AppKit / SwiftUI / Carbon / CryptoKit / ApplicationServices，不依赖第三方 Swift 包或 pip 包。`installer.py` 生成当前用户的路径，不写死作者主目录。

打包：

```sh
./package.sh
```

输出到被 Git 忽略的 `release/`，包含应用、安装程序、文档和 MIT 许可证，并生成 SHA-256 文件。不会打包 `~/Library` 中的数据、官方 hdc 或密钥。`build/` 是生成目录，请勿手工修改。

源码结构：

```text
Sources/main.swift          面板、历史、快捷键、直接粘贴
Sources/PhoneSettings.swift 手机地址设置
phone.py                    面板到同步服务的命令入口
Bridge/sync.py              文字双向同步、重连、服务控制
Bridge/capture.py           手机截图取回
installer.py                当前用户安装与 LaunchAgent 配置
build.sh / package.sh       构建与发行打包
```

## 验证范围

此前在实际 Mac / 手机环境验证过双向文字、无 USB 无线连接、手机锁屏期间从 Mac 写入后解锁粘贴、手机截图取回，以及面板直接粘贴、置顶和后台启动。Mac 休眠期间不会持续同步。

首个公开版本新增 IP/端口设置及安装流程；具体发行验证结果见 [CHANGELOG](CHANGELOG.md)。没有验证所有手机型号、旧 macOS、全新用户首次授权以及整机重启后的所有恢复场景。请不要将本工具作为重要数据唯一存储或要求强实时性的传输手段。
